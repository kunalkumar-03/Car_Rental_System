# 🚗 Car Rental System

A simple, console-based **Car Rental Management System** developed using Java and Object-Oriented Programming (OOP) concepts. The application allows users to view available cars, rent vehicles, calculate rental costs, and return rented cars through an interactive menu-driven interface.

## ✨ Features

- **Car Management:** Maintains car details including ID, brand, model, and rental price.
- **Car Availability:** Displays available cars for rental.
- **Rent a Car:** Allows customers to select and rent an available vehicle.
- **Customer Management:** Generates unique customer IDs and stores customer details.
- **Rental Price Calculation:** Automatically calculates the total rental cost based on the number of days.
- **Rental Confirmation:** Provides an option to confirm or cancel a rental.
- **Return a Car:** Allows customers to return previously rented vehicles.
- **Availability Updates:** Automatically updates car availability after renting or returning.

## 🛠️ Technologies Used

- **Language:** Java
- **Concepts:** Object-Oriented Programming (OOP)
- **Collections:** ArrayList
- **Input Handling:** Java Scanner

## 🧠 OOP Concepts Implemented

- **Encapsulation:** Uses private data members and public getter methods.
- **Classes & Objects:** Implements Car, Customer, Rental, and CarRentalSystem classes.
- **Abstraction:** Separates car, customer, and rental operations into dedicated classes.
- **Collections:** Uses ArrayList to manage cars, customers, and rental records dynamically.
